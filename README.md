# TRELLIS 2: RunPod ComfyUI template (batch 3D models)

> 📖 **Step-by-step guide:** [Generating textured 3D models in bulk with TRELLIS 2](https://tenitsky.com/guides/trellis-2-batch-3d-models/) · more free templates and ComfyUI guides at [tenitsky.com](https://tenitsky.com/)

Template files that set up **TRELLIS 2** in ComfyUI on RunPod and turn images into
textured 3D models, one at a time or in bulk.

- [`setup.sh`](setup.sh): installs the nodes, environments and model weights on first boot
- [`workflows/`](workflows): one-object and multiple-object 3D generation workflows
